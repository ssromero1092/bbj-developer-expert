# bbj-developer-expert

Skill global de GitHub Copilot para analisis y desarrollo de programas BASIS BBj con enfoque REVIEW FIRST.

## Alcance
- Analisis de programas `.bbj` y pantallas `.arc`.
- Propuestas tecnicas antes de implementar.
- Reglas para numeracion interna BBj y correlacion de lineas.
- Manejo de campos con ayuda (GZOOM) y dependencia de maestros/layouts.

## Estructura
- `SKILL.md`: reglas y flujo principal.
- `workflows/`: pasos operativos por etapa.
- `references/`: patrones tecnicos y criterios de evidencia.
- `knowledge/`: catalogo, convenciones y bitacora.
- `examples/`: ejemplos y guias de captura.

## Uso
En Copilot Chat:
- `/bbj-developer-expert` seguido del requerimiento.

## Mantenimiento
- Versionar cambios en Git.
- Actualizar `knowledge/knowledge-change-log.md` al modificar reglas.
- Probar una solicitud de analisis antes de publicar.
