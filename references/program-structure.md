# Program Structure Patterns

Plantilla para documentar estructura de programas BBj.

## Aspectos
- Punto de entrada y salida.
- Flujo principal y subrutinas.
- Dependencias llamadas desde el programa.
- Bloques de inicializacion y cierre.
- Numeracion interna de lineas BBj (si existe), incluyendo secuencia, rangos y correlacion entre bloques.
- Diferenciar referencias por numeracion interna BBj vs lineas del editor.

## Regla de trazabilidad
- Si el programa usa numeros de linea escritos, toda propuesta debe citar esos numeros como referencia primaria.
- Si se requiere una cita por editor, usarla como referencia secundaria.
- Validar que nuevos bloques mantengan orden y correlacion de la secuencia existente.
