# Workflow: Analyze Requirement (Review First)

## Objetivo
Entender el requerimiento BBj sin modificar codigo.

## Pasos
1. Reformular el requerimiento en terminos funcionales.
2. Identificar alcance: proceso, modulo, entrada/salida esperada.
3. Identificar criterios de aceptacion y restricciones.
4. Listar informacion faltante para analisis seguro.
5. Declarar explicitamente que no se implementara aun.

## Checklist de salida
- Requerimiento resumido.
- Resultado esperado medible.
- Restricciones tecnicas detectadas.
- Preguntas abiertas minimas necesarias.
- Confirmacion de modo REVIEW FIRST.
