# Workflow: Review Changes

## Objetivo
Verificar coherencia tecnica despues de implementar.

## Pasos
1. Resumir cambios por archivo y rutina.
2. Identificar impactos funcionales y tecnicos.
3. Revisar alineacion con patrones BBj del usuario.
4. Verificar, cuando aplique, que la numeracion interna BBj mantiene orden y correlacion.
5. Declarar pruebas realizadas y no realizadas.
6. Reportar riesgos residuales.

## Entregable minimo
- Lista de archivos tocados.
- Resumen de cambios por seccion/rutina.
- Confirmacion de correlacion de numeracion interna BBj (si aplica).
- Riesgos y pruebas pendientes.
- Pasos sugeridos para validacion manual del usuario.
